How to export everything

1

Icons → PNG: Right-click each icon above → "Save image as" won't work for inline SVGs.
Instead: go to cloudconvert.com/svg-to-png, upload icons/icon.svg, set output size to 128 → download. Repeat for 48 and 16.

2

Promo tiles → PNG: Use Chrome DevTools screenshot.
Open DevTools (F12) → Cmd+Shift+P → type "screenshot" → "Capture node screenshot" → click the promo tile element.
Or: use any screenshot tool at exact pixel dimensions.

3

Extension screenshots (5 needed):
Load the extension in Chrome → open ChatGPT → take screenshots at 1280×800 window size.
Capture: (1) button visible on page, (2) diff overlay open, (3) improved prompt for a work email, (4) improved prompt for cooking, (5) extension popup open.

4

Demo GIF for landing page:
